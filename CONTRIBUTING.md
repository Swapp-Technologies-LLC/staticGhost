## 🛠️ Developer Setup & Testing Workflow

1. Clone the repository and install dependencies:
   ```bash
   git clone https://github.com/Swapp-Technologies-LLC/staticGhost.git
   cd staticGhost
   npm install
   ```
2. Run the automated verification test suite to ensure everything passes:
   ```bash
   npm test
   ```
3. Test local desktop execution:
   ```bash
   npm start
   ```
