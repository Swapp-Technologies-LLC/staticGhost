🛡️ Security Notice & Token Best Practices

OS Keychain Encryption Active: All Personal Access Tokens are encrypted on disk using your operating system's native keychain (Windows DPAPI / macOS Keychain).

⚠️ Security Disclaimer: If an unauthorized third party gains physical access or remote control of your local computer account, stored credentials could potentially be used. We strongly recommend using Fine-Grained Personal Access Tokens restricted only to the target blog repository with minimum Contents: Read and write permissions.
